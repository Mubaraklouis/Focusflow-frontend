      • formatDate: (dateString: string, options?: DateFormatOptions) => string

        Formats a date string into a human-readable format

        Description

        Converts an ISO date string (YYYY-MM-DD) into a localized, human-readable format. Returns an empty string if the input is invalid.

        Example

        formatDate('2025-01-15')
        // Returns: "Jan 15, 2025"

        formatDate('2025-01-15', { includeDay: false })
        // Returns: "Jan 2025"

        formatDate('2025-01-15', { monthFormat: 'long' })
        // Returns: "January 15, 2025"

        formatDate('')
        // Returns: ""
      • formatWebsiteUrl: (url: string) => string

        Formats a website URL for display

        Description

        Removes the protocol (http:// or https://) from a URL for cleaner display in the UI. Also removes trailing slashes.

        Example

        formatWebsiteUrl('https://johndoe.dev')
        // Returns: "johndoe.dev"

        formatWebsiteUrl('http://example.com/')
        // Returns: "example.com"

        formatWebsiteUrl('')
        // Returns: ""
      • getInitials: (name: string) => string

        Extracts initials from a full name

        Description

        Takes a full name string and returns the uppercase initials. Handles single names, multiple names, and edge cases gracefully. Returns a maximum of 2 characters.

        Example

        getInitials('John Doe')
        // Returns: "JD"

        getInitials('John')
        // Returns: "J"

        getInitials('John Michael Doe')
        // Returns: "JM" (first two initials only)

        getInitials('')
        // Returns: "U" (default fallback)

        getInitials('  ')
        // Returns: "U" (handles whitespace-only strings)
